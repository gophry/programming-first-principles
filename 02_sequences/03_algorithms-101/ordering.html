Ordering

Strict Order — Axioms

a, b, g = 3, 7, 12
c, d = 7, 3
e, f = 5, 5

# == properties (equality)
f'Reflexivity: {a == a = }'                        # always True -- a equals itself
f'Symmetry:    {e == f = }, {f == e = }'

# < properties (strict order)
f'Irreflexivity: {a < a = }'                        # always False -- nothing is less than itself
f'Asymmetry:     {a < b = }, {b < a = }'             # True, False -- can't both be True
f'Equivalence:   {e < f = }, {f < e = }'            # False, False -- equivalent case still holds
f'Transitivity:  {a < b = }, {b < g = }, {a < g = }' # True, True, True -- a<b and b<g implies a<g
'Reflexivity: a == a = True'
'Symmetry:    e == f = True, f == e = True'
'Irreflexivity: a < a = False'
'Asymmetry:     a < b = True, b < a = False'
'Equivalence:   e < f = False, f < e = False'
'Transitivity:  a < b = True, b < g = True, a < g = True'

Strict Weak Order

  • irreflexive
  • asymmetric
  • transitive
  • equivalence

Think of ranking by age and tie.

Person = namedtuple("Person", ["name", "age"])

sheldon = Person("Sheldon", 30)
leonard = Person("Leonard", 30)
howard  = Person("Howard", 35)

f'{sheldon = }'
f'{leonard = }'
f'{howard = }'
print()
f'Irreflexivity: {sheldon.age < sheldon.age = }'
print()
f'Equivalent pair (Asymmetry):'
f'{sheldon.age < leonard.age = }, {leonard.age < sheldon.age = }'
print()
f'Ordered pair (Asymmetry):'
f'{sheldon.age < howard.age = }, {howard.age < sheldon.age = }'
print()
f'Transitivity:'
f'{sheldon.age < howard.age = }, {leonard.age < howard.age = }'
print()
f'Not a Total Order -- equivalence != equality:'
f'{sheldon.age < leonard.age = }, {leonard.age < sheldon.age = }, {sheldon == leonard = }'
"sheldon = Person(name='Sheldon', age=30)"
"leonard = Person(name='Leonard', age=30)"
"howard = Person(name='Howard', age=35)"
'Irreflexivity: sheldon.age < sheldon.age = False'
'Equivalent pair (Asymmetry):'
'sheldon.age < leonard.age = False, leonard.age < sheldon.age = False'
'Ordered pair (Asymmetry):'
'sheldon.age < howard.age = True, howard.age < sheldon.age = False'
'Transitivity:'
'sheldon.age < howard.age = True, leonard.age < howard.age = True'
'Not a Total Order -- equivalence != equality:'
'sheldon.age < leonard.age = False, leonard.age < sheldon.age = False, sheldon == leonard = False'

Total Order

  • irreflexive
  • asymmetric
  • transitive

Think of ranking by name,age but no tie.

sheldon = Person("Sheldon", 30)
leonard = Person("Leonard", 30)
howard  = Person("Howard", 35)

f'Total Order check: {sheldon.name < leonard.name = }, {leonard.name < sheldon.name = }, {sheldon == leonard = }'

f'Total Order check: {sheldon.name < howard.name = }, {howard.name < sheldon.name = }, {sheldon == howard = }'
'Total Order check: sheldon.name < leonard.name = False, leonard.name < sheldon.name = True, sheldon == leonard = False'
'Total Order check: sheldon.name < howard.name = False, howard.name < sheldon.name = True, sheldon == howard = False'

min/max bug int

def min_naive(a, b):
    return a if a < b else b   # a < b ? a : b

def max_naive(a, b):
    return a if b < a else b   # b < a ? a : b
a = 3000
b = 3001
c = 3000
f'{min_naive(a,b) = }'
f'{max_naive(a,b) = }'

min/max v1

  • take first only if strictly smaller
  • take first only if strictly larger
  • Ignores the tie
a = 4000
b = 4000
f'{id(a) = }, {id(b) = }'
min_val = a if a < b else b    # take a only if strictly smaller; tie → b
max_val = a if b < a else b    # take a only if strictly larger;  tie → b
f'{id(min_val) = }, {id(max_val) = }'
'id(a) = 4621898864, id(b) = 4621898928'
'id(min_val) = 4621898928, id(max_val) = 4621898928'

min/max Walter Brown

  • Is there a reason otherwise (out_of_order)
  • min: return a if in order, else b
  • max: return b if in order, else a
  • Stable means: if two items compare equal (a tie), they keep the order they already had.
